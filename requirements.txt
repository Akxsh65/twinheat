# Measured runtime (scripts/check_gpu.py on Kaggle 2x Tesla T4, sm_75):
#   Python 3.13.15, driver 580.178.04 (supports up to CUDA 13.0), torch 2.11.0+cu128,
#   cupy 14.0.1 (CUDA runtime 12.9), numba 0.61.2, numpy 2.1.3, scipy 1.16.3; pyamg absent.
# Kaggle already has a working GPU stack, so the pins marked [kaggle] equal the versions that
# check_gpu.py measured there; pip sees them as satisfied and does not reinstall them.

# cp311 (laptop, CLAUDE.md §4) and cp313 (Kaggle) and resolves together with the pins above.

# UNSURE: on a clean Linux venv the plain PyPI "torch==2.11.0" wheel is whichever CUDA build

# cupy-cuda12x 14.0.1 is the CUDA-12 wheel family, matching Kaggle's measured runtime 12.9 (so

# cupy-cuda12x; confirm with `pip list | grep -i cupy` there.
